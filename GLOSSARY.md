# Календарь звонков

Сервис записи на звонок: один владелец публикует доступное время, гость без регистрации выбирает тип встречи и бронирует свободный слот.

## Language

**Владелец**:
Единственный человек, который задаёт типы встреч и свободное время для звонков.
_Avoid_: пользователь, админ, хозяин календаря

**Гость**:
Человек без учётной записи, который выбирает тип встречи и бронирует слот.
_Avoid_: клиент, пользователь, посетитель

**Тип встречи**:
Шаблон звонка с названием, описанием и длительностью, который создаёт владелец.
_Avoid_: слот, событие, встреча

**Слот**:
Свободное время начала для конкретного типа встречи внутри окна записи.
_Avoid_: интервал, тайм-слот, свободное окно

**Запись**:
Занятый слотом интервал времени, привязанный к типу встречи и гостю.
_Avoid_: бронь, событие, встреча, слот

**Окно записи**:
14 календарных дней, в пределах которых гость может выбрать слот.
_Avoid_: горизонт, период, диапазон

**Рабочие часы**:
Интервал внутри дня, в котором владелец принимает звонки.
_Avoid_: расписание, доступность
