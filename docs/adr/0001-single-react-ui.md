# Единственный UI — React SPA

В проекте одновременно жили два интерфейса: Razor-страницы ASP.NET Core и React-приложение на Vite. Оставляем один UI — React SPA в `frontend/`; бекенд отдаёт только REST API из `api/` и страниц не рендерит. Причина: вся дальнейшая функциональность (выбор типа встречи, календарь, слоты, бронирование) интерактивна, а две оболочки означали бы два CSS-стека, две навигации и дублирующие тесты.

## Consequences

- Razor-скаффолд (контроллеры страниц, `Views/`, bootstrap и jquery) удалён.
- В разработке UI живёт на `:5173` (Vite), API — на `:5150`; запросы к `/api` проксирует Vite.
- Отдача собранного SPA бекендом не настроена. Если понадобится один origin, это отдельное решение.
